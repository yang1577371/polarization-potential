01能斯特方程

标准电极电势 E° 只描述“所有物质都处于标准态”时的电势。真实溶液里浓度几乎不可能是 1 mol/L，于是需要用能斯特方程把浓度折算进去：

E = E° + (RT / nF) · ln(aOx / aRed) a 为活度；稀溶液中常用浓度代替。R = 8.314 J·mol⁻¹·K⁻¹，F = 96485 C·mol⁻¹。

把常数代入、换成常用对数，25 ℃ 时得到课堂上最常见的形式：

E = E° + (0.0592 / n) · lg(cOx / cRed) 0.0592 V = 2.303RT/F 在 298 K 的数值，因此它只随温度改变，与 n 无关。

使用时有两条容易被忽略的规则：

  • 纯固体与纯液体活度取 1。所以 Cu²⁺/Cu 只与 c(Cu²⁺) 有关，Zn²⁺/Zn 同理；H₂ 在常压下也按 1 处理。
  • 系数要进入指数。Cl₂ + 2e⁻ ⇌ 2Cl⁻ 的 n = 2，c(Cl⁻) 取平方，化简后每十倍浓度变化对应 0.0592 V，而不是 0.0296 V。
电对E° / V25 ℃ 的能斯特式
Cu²⁺ / Cu+0.34E = 0.34 + 0.0296 lg c(Cu²⁺)
H⁺ / H₂0.00E = 0 − 0.0592 pH
Zn²⁺ / Zn−0.76E = −0.76 + 0.0296 lg c(Zn²⁺)
O₂ / OH⁻+0.40E = 0.40 − 0.0592 lg c(OH⁻)
Cl₂ / Cl⁻+1.36E = 1.36 − 0.0592 lg c(Cl⁻)
例题 1 单电对

求 25 ℃、c(Cu²⁺) = 0.010 mol/L 时 Cu²⁺/Cu 的平衡电势；若阴极超电势为 0.10 V，实际析出电势是多少？

  1. E = 0.34 + (0.0592 / 2) · lg 0.010 = 0.34 − 0.0592 = 0.281 V
  2. φc = E − ηc = 0.281 − 0.10 = 0.181 V

浓度从 1 mol/L 降到 0.01 mol/L，平衡电势下降了 0.0592 V；超电势再让它下降 0.10 V。两者方向相同，但机理完全不同。

02极化与超电势

上面的计算针对的是平衡态：没有电流通过，电极上正逆反应速率相等。一旦通电，电极电势就会偏离平衡值，这种现象称为极化，偏离的大小就是超电势：

η = |φ − E平| ≥ 0 η 永远取正值；方向由电极反应决定，见下式。
阴极：φc = E平 − ηc　（更负）
阳极：φa = E平 + ηa　（更正） 超电势是“额外推动力”：想让还原发生，电势必须比平衡值更低；想让氧化发生，必须比平衡值更高。
关

记住方向，就不会算错符号。阴极是“往下拉”，阳极是“往上推”。模拟器里的实线总是从虚线出发：阴极向负方向、阳极向正方向偏移。

2.1 电化学极化（活化极化）

电极反应包含一系列步骤：离子扩散到电极表面、失去溶剂化层、吸附、电荷转移、产物脱附。其中电荷转移步骤往往最慢，需要额外的电势来“推”过活化能势垒，这就是电化学极化。

它与电流密度 i 的关系可用 Tafel 方程描述：

η = a + b · lg i b 为 Tafel 斜率，常见 0.06–0.12 V/decade；a 与电极材料、表面状态、温度有关。

由此可见，电化学极化对电极材料极其敏感。同一个析氢反应，在镀铂黑电极上超电势只有几十毫伏，在锌或汞表面却可高达 0.7–1.0 V —— 这既是析氢过电位造成能量损失的原因，也是电镀与电池中选择电极材料的依据。

i

搅拌溶液几乎不能减小电化学极化，因为它慢在电荷转移而不是传质。这一点常被用来区分两类极化。

2.2 浓差极化

当反应消耗离子的速度超过扩散补充的速度时，电极表面附近的离子浓度 cs 会低于本体浓度 cb。由能斯特方程，浓度差直接转化成电势差：

ηconc = (0.0592 / n) · lg(cb / cs) cs 越接近 0，η 越大；当 cs → 0 时 η → ∞，此时电流达到极限。

极限电流密度由传质决定：

iL = n F D cb / δ D 为扩散系数，δ 为扩散层厚度。

因此浓差极化具有几个鲜明特征：溶液越稀、电流越大、搅拌越差，极化越严重；充分搅拌或升温可以显著削弱它。本站模拟器的“浓差极化”模式用 η = (0.0592/n)·(−lg c) 做了简化，因此把浓度滑到最低时偏离最明显。

03析出电势与析出顺序

把平衡电势与超电势合在一起，就得到析出电势：

阴极析出电势：φc = E平 − ηc
阳极析出电势：φa = E平 + ηa

多种离子共存时，比较的正是析出电势：

判

阴极（还原）：析出电势越正，越先析出。
阳极（氧化）：析出电势越负，越先析出。
注意是“实际析出电势”，不是标准电势 E°，也不只是平衡电势。

为什么方向相反？因为阴极反应消耗电子，电势越正意味着该电对越容易得到电子；阳极反应失去电子，电势越负意味着越容易失去电子。用一句话记：阴极挑“正”的，阳极挑“负”的。

例题 2 三选一

25 ℃，某溶液含 Cu²⁺、H⁺、Zn²⁺，浓度均为 0.1 mol/L，阴极超电势统一取 0.10 V。阴极上谁先析出？

离子E平 / Vφc / V顺序
Cu²⁺+0.31+0.211
H⁺−0.06−0.162
Zn²⁺−0.79−0.893

所以阴极依次析出 Cu、H₂、Zn。三者电势差距很大（约 0.7 V 量级），改变浓度（0.01–1 mol/L 范围内最多移动约 0.1 V）或统一超电势都无法改变这个顺序 —— 这也是为什么可以从含锌溶液中电积铜而几乎不析出锌。

当两种离子的析出电势很接近时，浓度与超电势就能改变顺序。工程上常利用这一点：电镀黄铜时加入配位剂，让 Cu 与 Zn 的析出电势靠近，从而实现共沉积；反之，若要分离两种金属，则应让它们的析出电势差尽量大。

04典型实例

4.1 电解食盐水：为什么阳极出氯气？

阳极上有两个竞争反应：

2Cl⁻ → Cl₂ + 2e⁻　　E° = +1.36 V
2H₂O → O₂ + 4H⁺ + 4e⁻　　E° = +1.23 V（pH 0）

两者标准电势只差 0.13 V。而氧气析出在石墨、金属阳极上的超电势通常有 0.4–0.8 V，氯气的超电势却很小（约 0.05 V）。于是氧的实际析出电势被抬到氯之上，Cl₂ 反而先析出。工业氯碱电解使用涂层钛阳极（DSA）正是为了在保持低氯超电势的同时抑制析氧。

注

该结论与 pH 密切相关：碱性条件下 O₂/H₂O 的平衡电势会大幅下降，析氧变得更容易。本站模拟器采用 O₂/OH⁻（E° = +0.40 V）这一碱性电对，所以在默认参数下 OH⁻ 先于 Cl⁻ 被氧化 —— 这与“酸性浓盐水”中的工业结论并不矛盾，只是条件不同。

阴极侧则是水的还原：2H₂O + 2e⁻ → H₂ + 2OH⁻。Na⁺ 的平衡电势低至 −2.71 V，远在氢气之后，因此钠离子留在溶液中。

4.2 电解水：1.23 V 与 1.8 V 的差距

理论上分解水只需要 1.23 V，但实际电解槽通常要 1.8–2.0 V。多出来的电压几乎都花在析氢与析氧的超电势以及溶液欧姆压降上，最终变成热。降低超电势（高性能催化剂、提高温度、增大电极面积）一直是电解水制氢的核心问题。

4.3 电解精炼铜：顺序决定纯度

粗铜作阳极、纯铜作阴极，电解液为硫酸铜溶液。通电后：

  • 阳极上 Cu 比 OH⁻ 更容易氧化（φa 更低），因此铜溶解进入溶液；
  • 比铜活泼的 Zn、Ni、Fe 也会溶解，但它们的析出电势比 Cu 更负，不会在阴极析出，留在电解液中；
  • 比铜不活泼的 Ag、Au、Pt 不溶解，直接落成阳极泥，成为提炼贵金属的原料；
  • 阴极上只有 Cu²⁺ 优先还原，得到 99.95% 以上的电解铜。

这正是“析出电势决定顺序”的工业版本：一个顺序，同时完成了提纯与副产物回收。

05常见误区

✕

只看 E° 判断顺序。E° 是标准态的数据。浓度改变 0.06 V/decade，超电势可以改变零点几伏，二者都可能让顺序颠倒。永远比较实际析出电势。

✕

把超电势一律当成“电势降低”。阴极确实更负，但阳极是更正。若统一写成减号，阳极的计算必错。

✕

以为搅拌能消除所有极化。搅拌只改善传质，对电荷转移迟缓导致的电化学极化几乎无效。

✕

认为浓度越低越容易析出。对阴极，浓度低使平衡电势更负，反而更难还原；对 Cl⁻ 这类阳极反应物，浓度低使其更难氧化。浓度对两极的作用方向需要具体分析。

✕

把 O₂ 与 Cl₂ 的先后当成固定结论。它取决于 pH、氯离子浓度、电极材料与电流密度。改变条件，顺序就可能改变 —— 这正是电化学有趣的地方。

06术语速查

术语含义
标准电极电势 E°标准态（活度为 1）下相对 SHE 的电极电势，25 ℃ 数值可查表。
平衡电势 E平给定浓度下由能斯特方程算出的电势，无净电流时的电极电势。
析出电势 φ实际发生析出（沉积或放出气体）时的电极电势，等于 E平 加上超电势的修正。
超电势 η|φ − E平|，恒为非负值。
电化学极化电荷转移步骤迟缓引起的极化，与电极材料密切相关，Tafel 关系。
浓差极化电极表面与本体浓度差引起的极化，搅拌可显著减小。
极限电流传质所能支持的最大电流，此时表面浓度趋近于零。
分解电压使电解开始持续进行所需的最小外加电压，约等于 φa − φc。
槽电压实际电解槽两端电压，等于分解电压加上欧姆压降与接触压降。
